## Launch sequence

1. Publish the public repository with the preview GIF at top, executable demo and source-visible QA checks.
2. Share a side-by-side: a generic animated stack of cards **versus** an original film directed with one continuous visual idea. Label both accurately; never pass off other creators' work as your own.
3. Include a copy/paste command `npx skills add Pedroshakoor/Motion-God-Mode` after confirming it installs from the public repository.
4. Record a 30-second walkthrough: prompt → `brief.md` → frame timeline → animated render → QA/contact sheet → revision.
5. Invite contributors to implement one more renderer (Remotion sample) or supply reproducible test cases, not generic praise.
6. Release improvements with visible before/after GIFs. Earn stars through actual artifacts, dependable installs and iteration.

No claim here guarantees virality or a particular star count.
