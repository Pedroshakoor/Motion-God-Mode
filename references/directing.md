# Directing playbook: make it feel authored

## The 11 laws

1. **Frame 0 is a poster.** A stopped scroll must already show a useful premise or arresting image. Avoid black intros, loading indicators and slow logo build-ups.
2. **One hero.** The story is carried by an object, a shape, a character or a word. That hero survives across scenes even when its form changes.
3. **Transform, don't shuffle.** A seam is a transformation: a circle becomes the dial of a product, a cursor becomes a comet, a door becomes the next scene's frame. Do not use generic wipes to disguise unrelated pictures.
4. **Move with hierarchy.** One lead motion, then one secondary. Avoid starting/stopping every element on the same frame. Make anticipation and follow-through legible.
5. **Easing has physical intent.** Use sprung arcs, settle and drag where they imply material. Linear movement is a choice for mechanical/process shots, not a default.
6. **Pacing needs contrast.** If everything is fast, nothing feels fast. Place 0.3–1.0 second holds after a burst where the composition is rewarding to look at.
7. **Type is an actor.** Animate its meaning: enter, mask, morph or reveal. Avoid arbitrary word-by-word subtitles over already self-explanatory pictures.
8. **Micro / wide / full.** Design for three scales. The tiny detail should deepen the macro idea, never become indispensable to comprehension.
9. **Watch without sound.** Main idea, action, and result must still read. Watch audio-only too: rhythm, emphasis, and release should make sense.
10. **Camera moves are motivated.** Pan/zoom only when a subject movement, reveal, or perspective change needs it. Motion blur should follow fast motion, never smear text to compensate for weak layout.
11. **No decorative debris.** Random particles, glow, gradient backgrounds, fake film grain and cliché glitch effects cannot substitute for a clear visual concept.

## Example of a real throughline

**Film:** 15-second product launch for a scheduling app.

- 0–1.5 s: A red overbooked calendar block physically crowds every pixel; a single free gap appears. The first frame immediately communicates the problem.
- 1.5–3 s: The gap stretches into a slot; a cursor drags a real-looking appointment card into it. Event color and type sampled from actual product if available.
- 3–5.5 s: The slot opens like a door; it becomes an enlarged real UI panel with visible confirmation, not a floating static screenshot.
- 5.5–8 s: One action reschedules a conflicting event. Before/after is evident from the actual UI components.
- 8–11.5 s: The UI panels line up into a clean rhythm; the same free gap is now visual negative space. A breath.
- 11.5–15 s: Shapes resolve to an authentic logo, truthful product name and verified URL. The final frame is usable as a still.

The seam is the gap. Sound uses the slot impact as a leitmotif. **Do not use this treatment verbatim**; it demonstrates construction, not a generic reusable ad.

## Timing grammar

- Establishing hook: within 0–1 second (earlier is better).
- Short type read: visual presence for ~0.7 s minimum, unless intentionally flashed as texture rather than copy.
- Common composition turnover: showreel ~1–2.5 s; product ~1.4–3.5 s. Longer holds are earned, never mandated.
- End mark: allow enough unbusy time to read brand/CTA, generally 1–2 seconds, scaling with copy length.
- Transitions: match subject, screen position, scale and directional impulse; abrupt edits usually align to audio hits (±1 frame).
- Never impose a universal cuts-per-second number. Emotion and information load choose the rhythm.
