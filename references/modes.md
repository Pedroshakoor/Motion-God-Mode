# Four production modes

## Showreel — motion design as the product

**Promise:** One evolving thought proves range without being a disconnected style sampler.

1. Pick a concrete transformation rule (circle → letter → gear → user interface → planet → dot).
2. Plan eight-ish compositions for a 15-second piece and two deliberate moments of rest.
3. Demonstrate contrasts: flat type, graphic geometry, spatial depth, live UI, physical/organic moment, final clean wordmark.
4. Put the most striking composed frame at frame zero and the most memorable transformation at the midpoint.
5. Avoid third-party brands and fabricated client logos or usage statistics.

**Failure:** rapid cuts among unrelated shaders; no idea remains in viewer's memory.

## Product — action proves value

**Promise:** Show the real product doing one useful thing, with a readable cause and outcome.

1. Find official product assets and verify the claims at the URL/source.
2. Pick the core user pain, then show an actual UI workflow with two meaningful actions.
3. Rebuild individual panels and interactions in HTML/SVG/React to animate pieces, not flatten them to screenshots.
4. Keep the brand's typography and proportions accurate. Show a result immediately following each action.
5. Use exact verified product name and link as last frame. If real UI cannot be accessed, limit output to a clearly labelled **concept** and do not assert it demonstrates functionality.

**Failure:** polished generic dashboard with made-up metrics masquerading as the real app.

## Launch story — the character carries the release

**Promise:** Short narrative with one emotional shift; reveal through action, not a branded voice-over dump.

1. Write 2–3 story options before production; pick based on readability and surprise.
2. Record poses: anticipation, reaction, held expression, change of intent, release.
3. Choreograph emotional pacing: setup (stillness) → escalation (movement) → pause (face) → surprise → signoff.
4. If using original generated references, do not silently turn them into unapproved on-screen art; original code-built character is preferred when brief requires code-only.
5. Max one or two verified facts, nested in world or consequence.

**Failure:** characters exist only to point at call-to-action text.

## Explainer — one causal chain

**Promise:** A concrete mental model the viewer understands and could retell.

1. State one question and one answer.
2. Sequence: hook → ordinary baseline → break → reveal mechanism → consequence → recap.
3. Voice script length at 125–145 words/min = 31–36 words for 15 s / 63–73 words for 30 s. Leave air for visuals and transitions.
4. On-screen labels summarize or provide examples: do not duplicate voice verbatim.
5. Use explicit object continuity: the same token, arrow or person persists across steps.

**Failure:** an animated slide deck with paragraphs on every card.
